两套预设，共用环境

release 和 debug 两套预设均纳入版本控制，可跨机器使用。 激活脚本将本机的 MRS2_ROOT 路径导出到当前 shell， CMake 直接读取该环境变量。

预设 构建类型 工具链路径 定义位置
release Release 当前 shell 的 MRS2_ROOT 纳入版本控制的 CMakePresets.json
debug Debug 当前 shell 的 MRS2_ROOT 纳入版本控制的 CMakePresets.json
如果未设置 MRS2_ROOT，配置阶段会立即停止。 工具链不会使用隐藏的默认路径，也不会回退到用户预设。
